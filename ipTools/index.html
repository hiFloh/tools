06 — IPv6

Private Subnet Generator (ULA)

Generates a random Unique Local Address prefix per RFC 4193 — the IPv6 equivalent of RFC 1918 private space. Uses your browser's cryptographic RNG for the 40-bit Global ID.

Locally-assigned ULAs always begin with fd. The Global ID is meant to be random and (practically) unique — not sequential or predictable — so every routed site can combine networks without prefix collisions.

Looking for something else?

Tools like ping/traceroute, WHOIS/RDAP lookups, reverse DNS, port scanning, or live BGP route lookups need a server to make outbound network calls on your behalf — they can't run purely client-side the way these calculators do. Good candidates to add next: an ACL/firewall rule builder, a subnet-diagram exporter, and a well-known ports reference.

Subnet Works — every calculation happens in your browser. No addresses are logged or transmitted.
